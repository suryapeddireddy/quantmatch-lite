# UI Context: QuantMatch-Lite

## Theme
Dark financial terminal mode only. Near-black backgrounds, high-contrast text, and distinct visual coding for Bids (Green spectrum) and Asks (Red/Orange spectrum) matching standard institutional exchange interfaces.

## Typography
- UI Text: Geist Sans (`--font-geist-sans`)
- Numbers & Prices (Monospace): Geist Mono (`--font-geist-mono`) — critical for price/quantity alignment in order book tables.

## Component Layout Patterns
- **Main Dashboard**: High-density 3-column layout (Order Entry Form on left, Central Order Book & Depth Chart, Trade Execution Ticker on right).
- **Border Radius**: Use `rounded-xl` for cards, inputs, and tables.
